# What stays is a made-up placeholder: a Windows profile of nobody in a WSL path.

# One entry per line: <path or glob> | <regular expression found in the line> | <reason>. What

# placeholder never carries a real name beside it. An entry whose glob starts with `wiki/`
# applies to the handbook's pages (scripts/export-public-wiki.sh); an entry of the repository
# that no line needs any more fails the test. An expression spells a name with a character class
# (`User[s]`) so that this list does not match itself.
