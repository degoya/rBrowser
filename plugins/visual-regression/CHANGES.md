# Changes

## 0.1.0

The first version (RB-050-04): the comparisons of the core's `visual.compare` as findings - a
view that differs from its baseline (with its share in percent, the areas and the diff image),
a size mismatch, a missing baseline, a view that could not be compared, and a comparison made
unreliable by another DPI, engine or engine version, viewport or full-page setting (an error
with `visual.failOnMetaMismatch`); machine and operating system are recorded, not compared.
